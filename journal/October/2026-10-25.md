## Problems and fixes

| Problem | Cause | Fix |
| --- | --- | --- |
| Pushed to the wrong repo name | Repo created as purple-team-lab, remote said purple-team-homelab | Corrected with `git remote set-url` |
| Git said "not a git repository" | Ran it from the parent folder; the zip created an extra folder layer | Moved into the repo folder |
| No Windows Server 2025 option in VMware | VMware's guest OS list not updated yet | Used the Windows Server 2022 profile |
| dc01 installed without a GUI | Picked Server Core instead of Desktop Experience | Kept Core: lower RAM use and smaller attack surface. Will configure with PowerShell |
| Unsure of the WAN gateway | 192.168.1.1 is the host's VMnet8 adapter, not the gateway | Confirmed VMware's NAT gateway is 192.168.1.2 in NAT Settings |
| ws01 got a 169.254 address and couldn't ping fw01 | pfSense em numbering didn't match VMware's adapter order, so LAN was on the wrong segment | Matched MACs from `ifconfig` to each VMware adapter and reassigned the segments |
| Stray `em1.1` interface | VLAN created by accident during interface assignment | To delete in the web UI |
| KeePassXC Auto-Type not working in VMware | VM focus and typing speed issues | Parked for now |
